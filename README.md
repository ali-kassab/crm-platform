# CRM Platform

A multi-tenant CRM for service and construction businesses: contacts, projects, jobs, real-time Kanban boards, finance rollups and a no-code automation engine.

Built with **Java 17 · Spring Boot 4 · PostgreSQL · Redis · React · Tailwind · shadcn/ui**.
